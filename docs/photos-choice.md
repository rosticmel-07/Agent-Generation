# Фото є. А що обрати?

Біль: підприємець має гарні фотографії, але клієнту бракує інформації для вибору. Два приклади — прибирання квартири й меблі на замовлення — показують, як сторінку можна адаптувати і до послуг, і до товарів.

## Фактична озвучка

Гарні фото є. Але клієнт не розуміє, що обрати?
Для послуг покажемо, що входить у вартість.
Для товарів — варіанти та умови замовлення.
Зберемо це на сайті під твій бізнес.
Односторінковий сайт — за сто п’ятдесят доларів.
Залиш заявку — обговоримо сайт для твого бізнесу.

Запис: Artem Klopotenko — Low, Rich and Deep, файл від 16.10.2026, Speed 1.11, Stability 57, Similarity 67, Style 27. Оригінальний MP3 збережений побайтно; для монтажу створено окремий 24-bit/48 kHz WAV із двопрохідним loudnorm. Темп і висоту голосу не змінено.

У наданій озвучці звучить «односторінковий сайт», хоча початкова чернетка містила «лендінг». Субтитри відтворюють запис; на екрані пропозиція названа «Лендінг під твій бізнес».

Зображення прибирання й меблів згенеровані спеціально для цього пояснення. Вони не видаються за портфоліо Bridge, реальних замовників або докази продажів. ## Матеріали й відтворення

- `src/BridgePhotosChoice.tsx` — окрема композиція, попередні ролики збережено.
- `data/photos-choice.json` — 6 сцен, 14 груп субтитрів.
- `data/words-photos-choice.json` — 41 одиниця синхронізації, число 150 як одна озвучена фраза.
- `data/alignment-photos-choice-provenance.json` — незалежне розпізнавання Whisper та узгодження з фактичним текстом; межі оцінені з кроком 20 мс.
- `data/captions-photos-choice.srt` — окремі українські субтитри.

```sh
npm run typecheck
node scripts/render-photos-choice.mjs --stills
node scripts/render-photos-choice.mjs --master
node scripts/export-photos-choice-from-master.mjs
python3 scripts/check-photos-choice-export.py
python3 scripts/package-photos-choice.py
```

4K рендериться безпосередньо з React-композиції у 2160×3840, 60 fps, 1320 кадрів. 1080×1920 зменшується Lanczos із майстра. H.264 High, CRF 12, slow, BT.709, AAC stereo. Фото має власну роздільність, зафіксовану в provenance; текст і векторні елементи рендеряться у 4K. У ZIP зберігаються ті самі MP4 без перекодування.

## Перевірки

Вісім кадрів перевірено при розмірі телефона: перший кадр, проблема, послуги, товари, два варіанти сторінки, ціна, фінал. Chromium перевіряє центр головних груп x=540, завантаження Oswald і вміщення ціни. Фінальний звіт після експорту: `data/photos-choice-export-report.json` — метадані, повне декодування, гучність, контрольні суми, перевірка попередніх експортів. Розпізнавання й синхронізація автоматичні; перевірка не заявляє прослуховування людиною.

Фінальні перевірки пройдено: обидва MP4 мають 1320 кадрів, 60 fps і повністю декодуються; звук −17,20 LUFS / −4,82 dBTP. Додатково переглянуто 26 декодованих кадрів фінального MP4 на розмірі 360×640, включно зі стиками сцен та першим кадром пропозиції. Порожню паузу перед появою ціни прибрано. Оригінальний MP3 і вісім попередніх MP4 збережено побайтно.
