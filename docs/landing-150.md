# «Лендінг за $150» — HQ, 60 fps

Рекламна версія Bridge Agency для Facebook та Instagram. Збережено основу V2: темний фон, червоні акценти, білу типографіку, макети, логотип і реальний кейс. Нове озвучення надано користувачем 10 жовтня 2026 року.

## Файли

- `previews/bridge-reel-150-hq-60fps.mp4` — основний файл для рекламного тесту: 1080 × 1920, 60 fps, 25 секунд.
- `previews/bridge-reel-150-master-4k-60fps.mp4` — майстер: 2160 × 3840, 60 fps, той самий монтаж. Векторні екрани відрендерені з коду у цій роздільності.
- `previews/landing-150-hq/index.html` — перегляд основного відео й галерея кадрів після завантаження репозиторію.
- `data/captions-150.srt` — субтитри; `data/words-150.json` — часові межі 48 слів/числових фраз.
- `previews/bridge-reel-150-originals-60fps.zip` — обидва оригінальні MP4, SRT і звіт експорту. Контрольні суми файлів в архіві перевірено.

Старий `bridge-reel-150-layout.mp4` — архівний 22-секундний макет без диктора. Його не замінено новим файлом; для запуску реклами використовувати HQ-файл вище.

## Монтаж

| Час за новою озвучкою | Екран |
| --- | --- |
| 0–2,92 с | Заголовок повністю видно з першого кадру; макет профілю, рух курсора й акцент на відсутній ціні |

| 5,68–10,70 с | Інтерфейс збирається за коротку послідовність; послуги, роботи, ціни та заявка підсвічуються за словами диктора |

| 18,78–25 с | Та сама картка плавно стає компактною; CTA, адреса, кнопка. Після короткої появи фінал залишається стабільним |

Ціна має одну постійну картку, яка охоплює дві останні сцени, тому немає накладання старої та нової копій. Фінальна кнопка закінчується на y=1270, адреса розташована над нею. Субтитри — переважно y=1440…1565; важливий вміст залишає запас праворуч і внизу під інтерфейс розміщення. Фактичний опис і рекламну кнопку перевіряти в перегляді відповідного розміщення Meta.

Усі анімації обчислюються для кожного кадру на 60 fps. Перехід на 60 fps не зроблено дублюванням кадрів старого MP4. Тривалість анімацій збережена через нормалізацію часу; вони не стали вдвічі швидшими.

## Голос і субтитри

Використано точний наданий файл `ElevenLabs_2026-10-10T12_16_21_Artem Klopotenko - Low, Rich and Deep_pvc_sp112_s50_sb69_se25_m2.mp3`. Оригінал зберігається як `public/audio/voiceover-150.mp3`. Голос не прискорювали і не розтягували; змінено тільки рівень у міксі.

Файл триває 22,988 с; остання фраза закінчується приблизно на 22,60 с. Відео триває 25 с, щоб дати час прочитати фінал. Озвучка містить усі шість погоджених фраз. У записі звучить «і чекати», тому субтитри відповідають цьому формулюванню. Для фінального міксу додано 3 dB загального підсилення без компресії динаміки або зміни темпу; піки перевірено після експорту.

Текст незалежно розпізнано Whisper small, після чого визначено часові межі відомого тексту через cross-attention DTW. Числа 150 та 50 вирівняно як цілі фрази; Instagram показано в оригінальному написанні. Отримано 16 груп субтитрів із підсвічуванням поточного слова. Походження аудіо, SHA-256 та незалежна транскрипція — у `data/alignment-150-provenance.json`.

Автоматичні межі оцінюються на сітці 20 мс. Перевірка транскрипції та кадрів не є окремою перевіркою прослуховуванням людиною.

Фонова атмосфера та звуки інтерфейсу створені власним скриптом без сторонньої музики. Під голосом атмосфера тихіша; наприкінці вона плавно завершується.

## Чіткість

- Майстер відрендерено з React/Remotion у 2160 × 3840. Це дає чітке джерело для основного 1080p-файла.
- Основний рекламний файл отримано з майстра зі зменшенням Lanczos, H.264, CRF 12, preset slow, yuv420p, BT.709, AAC. Параметри експорту спрямовані на високу якість, а не мінімальний розмір.
- Кейс повторно знято з оригінального вихідного коду на 60 fps при viewport 600 × 450 і device scale factor 3: джерело 1800 × 1350, H.264 CRF 10. Всього 151 кадр, а не інтерполяція 30 fps-файла.
- Старе зображення кейсу з PDF не використовується в новому ролику. Логотип залишається наданим растровим матеріалом; його вихідна деталізація обмежена PDF.
- Для оцінки якості завантажувати оригінальний MP4. Вбудований вебперегляд, пересилання через месенджер або публікація в соцмережі можуть мати власне стиснення.

## Відтворення

```sh
npm run typecheck
npm run preview:stills -- --composition=BridgeLanding150 --final
npm run render -- --composition=BridgeLanding150 --final
npm run render -- --composition=BridgeLanding150 --final --master
node scripts/export-150-from-master.mjs
```

Команда без `--master` рендерить 1080p безпосередньо з коду на 60 fps; команда з `--master` рендерить 4K. `export-150-from-master.mjs` зменшує цей майстер до основного файла й потребує FFmpeg у PATH або змінній `FFMPEG_EXECUTABLE`. Файл для цього рекламного тесту зменшено саме з 4K-майстра. Для відтворення звукового шару: `python3 scripts/make-atmosphere.py --landing-150`.

Мікс нового рендеру вже має підсилення з `mix_gain_db` і відповідну позначку в метаданих. `node scripts/master-150-audio.mjs` може додати це підсилення старішому майстру без зміни відеокадрів; повторно його не застосовує.

Перевірки й характеристики готових файлів: `data/landing-150-export-report.json`.
