# «Лендінг за $150» — рекламна версія V2

Стилістика й графічні елементи V2 збережені. Нова композиція `BridgeLanding150`: 1080 × 1920, 30 fps, початковий макет — 22 секунди. V1, V2 та їхня озвучка залишаються окремими матеріалами.

**Статус:** екрани та справжній рух сторінкою кейсу зібрані. Файл `bridge-reel-150-layout.mp4` — перегляд монтажу з тихою атмосферою, **без нового диктора**. Субтитри наразі стоять у запропонованих вікнах сцен; вони ще не синхронізовані з аудіо. Фінальний рекламний MP4 потребує нової озвучки.

## Новий текст для ElevenLabs

Не додавати часові позначки до поля озвучки. Один файл із послідовним голосом і природними паузами:

> Клієнт не знаходить ціну у твоєму Instagram?
>
> Не кожен готовий писати й чекати відповіді.
>
> Збери послуги, роботи, ціни та форму заявки на одному сайті.
>
> Ось один із сайтів, який ми створили.
>
> Лендінг за сто п’ятдесят доларів. Перші п’ятдесят відсотків — після затвердження дизайну.
>
> Залиш заявку — обговоримо сайт для твого бізнесу.

Голос: **Artem Klopotenko — Low, Rich and Deep**. Орієнтир налаштувань із назви попереднього файла: Speed 1.10, Stability 50, Similarity 69, Style 24. Зберегти попередню модель голосу. Не застосовувати монтажне прискорення, обрізання слів або обов'язкову паузу до початку. Якщо реальна озвучка виходить трохи довшою, спочатку оцінюємо її й коригуємо монтаж із читабельним фіналом.

У поточному середовищі немає підключеного ElevenLabs або налаштованого ключа. Найшвидший наступний крок — згенерований користувачем MP3/WAV. Для роботи через API потрібне окреме захищене налаштування секрету та точний voice ID, а не публікація ключа у файлах репозиторію.

## Екрани

| Вікно макета | Основний зміст |
| --- | --- |
| 0–3 с | «У твоєму Instagram не знаходять ціну?» — повністю видно вже на першому кадрі; макет профілю без ціни |
| 3–6 с | «Писати. Чекати. Чи шукати далі?» — повідомлення «Скільки коштує?» й очікування, без твердження про конкурента |
| 6–10 с | «Усе про твої послуги — за одним посиланням» — чотири елементи в одному інтерфейсі, поява за коротку послідовність |
| 10–14 с | «Ось як це може виглядати» — справжня сторінка композитної сітки, рух до справжньої форми, підпис про реальний проєкт |
| 14–18 с | «Лендінг за $150»; дизайн, тексти, розробка; перші 50% після затвердження дизайну; домен і хостинг окремо |
| 18–22 с | Ціна залишається на тому самому місці; стабільні CTA, адреса, червона кнопка, логотип |

Важливий вміст розташований переважно в межах x=96…900 та y=160…1550. Кнопка закінчується на y=1270, адреса розташована над нею. Остаточно перевірити розміщення в перегляді рекламного кабінету з фактичним інтерфейсом Meta, оскільки опис і елементи розміщень можуть відрізнятися.

## Справжній кейс

Джерело, надане користувачем: [KompoSite](https://rosticmel-07.github.io/KompoSite/). Вихідний код отримано з відповідного репозиторію `rosticmel-07/KompoSite` та відображено локально без зміни вмісту сторінки. Оригінальні шрифти Manrope/Oswald завантажені локально для відтворення; анімації появи завершені перед зніманням. Форму не відправляли. Нових відгуків, показників або гарантій не додавали.

`public/brand/composite-scroll.mp4` містить 120 кадрів справжньої сторінки: пропозиція → коротке прокручування → форма. Походження, commit джерела й параметри захоплення записані в `data/composite-capture-provenance.json`. Це знімання локальної копії вихідного коду; пряме відкриття опублікованого сайта було недоступне через мережевий проксі.

Звукова атмосфера синтезована власним скриптом, без сторонньої музики. Після додавання нового голосу рівні зводимо й перевіряємо заново.

Перевірено для поточного макета: TypeScript без помилок; перший кадр, усі сцени та фінал у масштабі 360 × 640; безперервні межі сцен; MP4 повністю декодується. Відео H.264, yuv420p, BT.709, 1080 × 1920, 30 fps, 660 кадрів. Контейнер із AAC має тривалість 22,016 с; пік фонової атмосфери −29 dBFS. Старий MP4 V2 збігається з попередньою версією побайтово. Перевірку відповідності нової озвучки та точності синхронізації ще не виконано — нового голосового файла немає.

## Запуск і завершення

```sh
npm run preview:stills -- --composition=BridgeLanding150
npm run render -- --composition=BridgeLanding150
```

Для відтворення атмосфери: `python3 scripts/make-atmosphere.py --landing-150`.

Після отримання озвучки:

1. Перевірити її текст і тривалість, зберегти окремо від початкового треку.
2. Визначити межі слів за новим аудіо, перевірити числа й «Instagram», перебудувати субтитри.
3. У `data/landing-150.json` вказати голосовий файл, реальні межі сцен і субтитрів, тривалість, рівень звуку та статус `timing_status: "audio_aligned"` після перевірки.
4. Перевірити всі переходи, зокрема 14–18 с, фінальний стабільний екран і рівні міксу. За зміни тривалості сцени кейсу узгодити довжину його прокручування.
5. Виконати `npm run render -- --composition=BridgeLanding150 --final`. Результат: `previews/bridge-reel-150.mp4`. Команда фінального експорту перевіряє наявність нового голосового файла та статус його синхронізації.
