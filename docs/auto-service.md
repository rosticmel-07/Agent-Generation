# Автосервіс — шлях однієї заявки

Статус: підготовка сценарію та коду екранів, очікується озвучка й оригінальний файл нової іконки. Це не готовий рекламний MP4. Межі сцен у `data/auto-service.json` попередні: після отримання запису потрібно вирівняти повну озвучку й субтитри та переобчислити монтаж. Не обрізати й не прискорювати голос заради 30 секунд.

## Ідея

Власник СТО працює з автомобілем, а запити про послуги, ціну й запис приходять у повідомленнях. Показуємо, як різні інструменти Bridge можуть допомогти представити послуги та прийняти звернення. Немає обіцянок гарантованих клієнтів або автоматично підтвердженого запису. Це демонстрація інтерфейсів для ніші, а не вигаданий реальний кейс Bridge.

Візуальна відмінність: одна червона мітка заявки проходить маршрут «реклама → сайт → звернення в Telegram». Нова іконка Bridge стає з’єднанням між модулями та знаком на фінальному екрані. Рух великих макетів і текстові маски запозичують загальний монтажний принцип із референса; чужі кадри, озвучка, бренд, лаймова палітра, екранні кнопки Instagram та текст не переносяться.

## Дані послуг

Запитаний актуальний URL: https://www.bridgeagency.com.ua/#services . Станом на 2026-10-19 прямий запит, звичайний браузер і запит після дозволу мережевого доступу не дали сторінки: мережевий шлюз повертає403. Поточний сайт **не перевірено**. Два домени додано до чернетки мережевих налаштувань; збереження чернетки не змінює поточне середовище.

Є попередній PDF головної від користувача від2026-10-09: `public/brand/home-1.png` і `home-2.png`. У ньому чотири послуги: лендінг під ключ, багатосторінковий сайт, Telegram-бот, сайт + реклама. Чернетка використовує саме їх, без цін. Не називати це повним актуальним переліком без перевірки. CRM, Discord і розробку довільного софту з чужого референса не додано до пропозиції.

## Текст для озвучки

Файл: `public/audio/voiceover-auto-service-draft.txt`. Це чернетка за останнім доступним PDF; назви послуг потрібно звірити з поточним сайтом або повідомленням користувача до запису.

> Поки ти ремонтуєш авто, клієнт знову питає: «Яка ціна? Як записатися?»
>
> Лендінг під одну послугу. Багатосторінковий сайт — для всього автосервісу.
>
> Telegram-бот — для звернень. Сайт із рекламою у Facebook та Instagram — щоб про тебе дізналися.
>
> У Bridge Agency підберемо інструменти під твою задачу.
>
> Напиши «СТО» у приватні повідомлення — обговоримо твій автосервіс.
>

## Екрани

1. Велике кінематографічне зображення авто на підйомнику, звернення про діагностику; заголовок «Ти під авто. Клієнт чекає?» з першого кадру.
2. Великі повідомлення про вартість, послуги й запис.
3. Велика сторінка автосервісу: послуги та форма звернення через кнопку. Поява навігації показує перехід від лендінгу до багатосторінкового сайта.
4. Читабельний Telegram-інтерфейс із вибором діагностики та запитом номера. Без вигаданого підтвердженого клієнта, персональних даних або графіка вільних слотів.
5. Чотири пов’язані модулі послуг та Bridge icon посередині.
6. Єдиний маршрут звернення: реклама → сторінка послуг → Telegram. Крапка й підсвічування напрямку; без показників конверсії.
7. Один заклик: «Напиши “СТО” у приватні повідомлення». Фінал після вирівнювання тримати2–3секунди.

Чорне тло, біла типографіка, червоні акценти; локальні Oswald і Manrope. Основна область шириною804px, центрx540, низ важливих груп не нижче1600. Під субтитри зарезервовано y1450–1580. Короткі завершені фрази додаються за реальною озвучкою, без випадкового дроблення слів і дублювання заголовків.

## Файли та запуск

`src/BridgeAutoService.tsx` — код семи сцен. `data/auto-service.json` — стан джерел і попередній план. Нова іконка відома лише як зображення в повідомленні: її оригінальний PNG/SVG не доступний як локальний файл. У макетах використано старий логотип із PDF як явну технічну заміну; фінальний рендер із ним заблокований. Не перемальовувати й не деформувати нову іконку.

```sh
npm run typecheck
node scripts/render-auto-service.mjs --stills
```

Вісім справжніх Chromium-кадрів макета зберігаються в `previews/auto-service-layout`. Перевірка включає завантаження шрифтів, центр основних груп, безпечні межі й ширину тексту. Після озвучки: повне вирівнювання → субтитри → перевірка кадрів/переходів → нативний2160×3840/60fps CRF12 рендер →1080p → повне декодування й перевірка звуку → ZIP. Команда фінального експорту навмисно відхиляє відсутні голос, синхронізацію, актуальний перелік послуг або оригінальну іконку.

Попередній готовий клінінговий ролик, його MP4, звук і звіти не змінюються.

Ілюстрація автосервісу: `public/illustrations/auto-service/diagnostics.png`, 1254×1254, створена генератором зображень для цього ролика. Оригінал лишається у `/workspace/generated_images`. Це візуальна ілюстрація, не реальний кейс або фото клієнта. CSS задає кадрування й делікатний рух; файл не редагується.
