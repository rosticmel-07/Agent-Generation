# Автосервіс — шлях однієї заявки

Композиція `BridgeAutoService`,26с,1080×1920,60fps/1560кадрів. Майстер рендериться нативно у2160×3840; фінальний1080p отримується черезLanczos. Це наступний ролик після клінінгу; попередні відео й оригінальні озвучки зберігаються.

## Сюжет і монтаж

Майстер зайнятий автомобілем, а клієнт питає про вартість і запис. Сторінка пояснює послуги; Telegram-бот допомагає прийняти звернення; реклама знайомить із сервісом. Один червоний світловий сигнал проходить через ці інтерфейси й з’єднується зі знакомBridge у блоці послуг. Макети демонстраційні, без вигаданих цін, реальних клієнтів, підтверджених записів або гарантій результату реклами.

|Сцена|Час|Зміст|
|---|---|---|
|Проблема|0–2,56|Авто на підйомнику, питання клієнтів; заголовок видно з першого кадру|
|Повідомлення|2,56–5,20|Дві великі репліки, синхронні з «Яка ціна? Як записатися?»|
|Сайт|5,20–10,66|Лендінг перетворюється на сторінку з навігацією на словах про багатосторінковий сайт|
|Бот|10,66–13,06|Вибір діагностики та запит контакту, без повідомлень про отриманого клієнта|
|Маршрут|13,06–17,24|Реклама → сайт із послугами → звернення вTelegram|
|ІнструментиBridge|17,24–23,00|Чотири модулі та знакBridge як центр з’єднань; тут починається голосовий заклик|
|Звернення|23,00–26,00|«Напиши “СТО” у приватні повідомлення», «Обговоримо твій автосервіс»; стабільний3-секундний фінал|

Межі округлюються до кадру60fps:0,154,312,640,784,1034,1380,1560. Перші рядки заголовків і основний вміст видимі одразу; наступні елементи входять короткими м’якими появами. Зміна сцен взаємовиключна, старі заголовки не перехрещуються з новими.

Основна область804px із центромx540; важливі групи закінчуються доy1600. Субтитри — завершені фрази по1–2рядки,48px, y1440; слово підсвічується за вирівнюванням. Діалоги клієнтів і фінальний великий текст самі виконують роль синхронних субтитрів, тому тотожний нижній напис вимкнений. SRT містить усі50одиниць повного запису.

## Повна озвучка

Джерело: наданий користувачем `ElevenLabs_2026-10-19T19_27_49_Artem Klopotenko - Low, Rich and Deep_pvc_sp112_s59_sb67_se30_m2.mp3`. Оригінал — `public/audio/voiceover-auto-service.mp3`, контейнер25,756688с; останнє слово закінчується приблизно на25,36с. Запис використовується повністю, без обрізання, зміни темпу або висоти голосу.

`prepare-auto-service-audio.py` створює окремий24-bit/48kHz WAV двопрохіднимloudnorm, ціль−17LUFS/−2dBTP. ОригінальнийMP3 лишається byte-identical. Тиха синтезована атмосфера — окремийWAV, створений `make-auto-service-atmosphere.py` без сторонніх музичних записів.

Вирівнювання: Whisper small, незалежне розпізнавання та forcedDTW за прийнятим текстом. Злиті окрема пунктуація йTelegram-бот; часові вікна взято з незалежногоASR після поелементного зіставлення. НазвиBridge Agency/Facebook/Instagram/СТО відображаються за прийнятим сценарієм. Сирі результати обох проходів збережені; точність меж орієнтовно20мс. Людське прослуховування не заявляється.

Файли: `data/auto-service-source-audio.json`, `data/alignment-auto-service-forced-raw.json`, `data/words-auto-service.json`, `data/captions-auto-service.srt`, `public/audio/voiceover-auto-service.txt`.

## Послуги й матеріали

Наданий користувачем запис підтвердив чотири рекламовані послуги: лендінг, багатосторінковий сайт, Telegram-бот і сайт із рекламою уFacebook/Instagram. Їх початкове джерело — попередній користувацькийPDF головної. Актуальну повноту живого сайта не підтверджено: хмарний шлюз повертав403. Цін у цьому ролику немає. CRM, Discord і довільний софт із конкурентного референса до пропозиції не додані.

Нова іконка була доступна лише як inline-зображення в повідомленні, окремого локальногоPNG/SVG немає. Ця версія використовує справжній наявний знакBridge: CSS відкриває символ із `public/brand/logo.png` усередині скляного блока, зберігаючи пропорції. Це явно розкрита альтернатива; точну нову іконку не перемальовано й не згенеровано. Після отримання її оригіналу можна замінити `plan.icon`, не змінюючи решту монтажу.

Ілюстрація `public/illustrations/auto-service/diagnostics.png` згенерована для цього ролика,1254×1254. Це візуалізація автосервісу, не реальний клієнтський кейс. Кадрування й делікатний рух задаютьсяCSS; вихідний файл не редагується. Локальні шрифтиOswald іManrope мають підтримку української та ліцензіїOFL.

Референс `IMG_9944.MP4` використано для аналізу ритму, великих макетів, руху камери й текстових появ. Чужі кадри, озвучка, текст, бренд, зелена палітра та елементиInstagram не копіюються. Власний прийомBridge — світловий шлях одного звернення та брендований центр інструментів.

## Відтворення

```sh
npm run typecheck
python3 scripts/prepare-auto-service-audio.py
python3 scripts/make-auto-service-atmosphere.py
node scripts/render-auto-service.mjs --stills
node scripts/render-auto-service.mjs --master
node scripts/export-auto-service-from-master.mjs
python3 scripts/check-auto-service-export.py
python3 scripts/review-auto-service-video.py
# Після візуального перегляду actual_video_visual_review у звіті:
python3 scripts/package-auto-service.py
```

Нативнийрендер: Chromium,PNG-кадри,scale2,CRF12/slow,concurrency2,H.264/yuv420p/BT709,AAC320k/stereo. Метадані, повне декодування, гучність/піки, довжина голосу заPCM-семплами, межі субтитрів, шрифти й14попередніхMP4 перевіряються скриптом. Кадри готовогоMP4 витягуються окремо для перегляду. ZIP зберігає точніMP4 без повторного стиснення та звіти зSHA-256.

Фінальний стан: обидваMP4 пройшли повне декодування та перевірки. Переглянуто55кадрів готового1080p у масштабі360×640 і повнорозмірнийкадр14,2с. Звук−17,12LUFS/−4,72dBTP; відеоряд26с/1560кадрів, контейнер26,005с черезAAC-пакування. Довжина оригіналу йWAV однакова:1236324PCM-семпли при48kHz. Максимальна похибка центру основних груп0px.14попередніхMP4 та вихідні озвучки збереглиSHA. Звіти: `data/auto-service-export-report.json`, `data/auto-service-video-review.json`.

Основні діалоги й фінальний текст лишаються стабільними; синхронне червоне підсвічування застосовується до нижніх фраз субтитрів.
